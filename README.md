# Dashboard de Vendas do Xbox Game Pass

Este projeto apresenta um dashboard interativo desenvolvido em Excel para análise de vendas e assinaturas do Xbox Game Pass, incluindo EA Play e Minecraft Season Pass.

## 📊 Visão Geral

O dashboard foi criado para fornecer uma visão completa das vendas de assinaturas do Xbox Game Pass, permitindo análise de diferentes tipos de assinatura e acompanhamento de performance de vendas.

## 🎮 Funcionalidades

### Filtros Interativos
- **Tipo de Assinatura**: Filtro por período de assinatura
  - Anual
  - Mensal  
  - Trimestral (selecionado por padrão)

### Painéis de Análise

#### 1. Total de Assinaturas EA Play Season Pass
- Exibe o valor total das vendas de assinaturas EA Play
- Valor atual: **R$ 990,00**
- Interface com logo oficial do EA Play

#### 2. Total de Assinaturas Minecraft Season Pass  
- Mostra o valor total das vendas de assinaturas Minecraft
- Valor atual: **R$ 1.140,00**
- Design com logo característico do Minecraft

#### 3. Total de Assinaturas Xbox Game Pass
- Apresenta análise comparativa de usuários com e sem Xbox Game Pass
- Gráfico de barras horizontais mostrando:
  - **Com Game Pass**: R$ 1.502,00 (maior volume)
  - **Sem Game Pass**: R$ 806,00 (menor volume)

## 📁 Arquivos do Projeto

- `Vendas do Xbox com Excel.xlsx` - Dashboard principal interativo
- `base.xlsx` - Base de dados com informações das vendas
- `README.md` - Este arquivo de documentação

## 🎯 Características do Dashboard

### Interface Visual
- **Cores**: Paleta verde, branco e cinza para uma aparência profissional
- **Layout**: Sidebar esquerda com filtros e área principal com painéis
- **Responsividade**: Design otimizado para visualização em diferentes tamanhos

### Personalização
- Bem-vinda personalizada: "Bem vinda, Cintia"
- Período de cálculo configurável: 01/01/2024 - 31/12/2024
- Data de atualização: 27/09/2025 18:00:00

## 📈 Insights Principais

1. **Minecraft Season Pass** apresenta o maior volume de vendas (R$ 1.140,00)
2. **EA Play Season Pass** tem o menor volume (R$ 990,00)
3. **Usuários com Xbox Game Pass** geram mais receita que usuários sem assinatura
4. A diferença entre usuários com e sem Game Pass é significativa (R$ 696,00)

## 🚀 Como Usar

1. Abra o arquivo `Vendas do Xbox com Excel.xlsx`
2. Use os filtros na sidebar esquerda para analisar diferentes períodos
3. Visualize os painéis principais para acompanhar métricas de vendas
4. Atualize os dados conforme necessário na base de dados
